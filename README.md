La liseuse interroge directement `main/tome-1/manuscrit.md`. Pour publier une correction, mettre à jour **ce fichier**, en gardant les en-têtes au format `## Chapitre 1 — Titre` jusqu'au chapitre 31. Le lecteur recharge la nouvelle version après actualisation ; s'il reste ouvert, il contrôle aussi les mises à jour toutes les trois minutes.

L'atelier de rédaction et les notes non publiques se trouvent dans le dépôt privé `ondersimsek5513-dot/histelia`. **Une modification de ce dépôt privé seul ne met pas à jour le manuscrit public.** Lors de la validation de chaque correction, synchroniser les deux textes dans le cadre du travail éditorial.
